# Analytics Funnel Optimization Project
## Overview
Built a landing page and implemented Amplitude Analytics to track user behavior and measure engagement with key call-to-action (CTA) buttons.
## Objective
The goal was to understand how visitors interact with a landing page and measure conversion behavior through event tracking and funnel analysis.
## Tools Used
	•	Amplitude Analytics
	•	HTML
	•	JavaScript
	•	Replit
## Implementation
### Landing Page
Created a business analytics landing page called DataPulse featuring:
	•	Sign Up CTA
	•	Request Demo CTA
	•	Interactive user interface
### Event Tracking
Implemented event tracking for:
	•	Sign Up Button Click
	•	Request Demo Button Click
	•	Page Viewed
### Funnel Analysis
Built a funnel to analyze:
	1.	Page Viewed
	2.	Sign Up Button Click
This helped measure how many visitors engaged with the primary conversion action.
## Results
	•	Successfully implemented Amplitude Analytics on a custom landing page.
	•	Captured and analyzed user interaction events.
	•	Created a funnel visualization to measure conversion behavior.
	•	Demonstrated how user actions can be transformed into measurable business metrics.
	•	Developed practical experience with event instrumentation and product analytics.
## Key Findings
	•	User interactions can be tracked and analyzed in real time.
	•	Funnel analysis provides visibility into conversion performance.
	•	Event tracking enables data-driven decision-making.
	•	Product analytics helps identify opportunities to improve user engagement.
